# Skills

Domeinkennis die een agent nodig heeft bovenop de rules. Waar een rule zegt *wat* de conventie is, legt een skill uit *hoe* je ermee werkt en welke valkuilen erbij horen.

| Skill | Waarvoor |
|---|---|
| [`okx-public-artefact`](okx-public-artefact/SKILL.md) | Schrijven, wijzigen of reviewen van een document in dit repository |
| [`okx-schrijfstijl`](okx-schrijfstijl/SKILL.md) | De schrijfnorm voor lopende tekst: taal, vaktermkeuze, argumentatie, stijl en structuur |

Deze map staat bewust op het echte pad en niet achter een symlink: GitHub volgt symlinks niet in blob-URL's, waardoor verwijzingen ernaartoe dood zouden zijn.
