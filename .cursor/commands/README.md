# Commands

Opgeslagen opdrachtteksten die je met **`/`** in de chat start. Ze leggen terugkerende workflows in dit repository vast, zodat je niet elke keer dezelfde lange instructie hoeft te typen.

| Command | Waarvoor |
|---|---|
| [`prep-repo-context`](prep-repo-context.md) | Een agent inlezen op dit repository voordat je aan het werk gaat |
| [`nieuwe-specificatie`](nieuwe-specificatie.md) | Een koppelingspecificatie of payload-specificatie opzetten vanuit het template |
| [`overhevelen-uit-meta`](overhevelen-uit-meta.md) | Een artefact uit de meta-repository hierheen brengen, in zeven stappen |
| [`controleer-document`](controleer-document.md) | Een document nalopen voordat het als pull request wordt voorgesteld |
| [`release-voorbereiden`](release-voorbereiden.md) | Bump bepalen, baseline controleren, release notes samenstellen |
| [`commit-message-nl`](commit-message-nl.md) | Een commit message schrijven |

`overhevelen-uit-meta` is de belangrijkste: overhevelen is geen kopieeractie. De inhoud verandert van karakter, van werkdocument naar releaseartefact, en dat vraagt om opgeschoonde bestandsnamen, herschreven verwijzingen, verwijderde issueverwijzingen en een uitgeschreven aanleiding.
